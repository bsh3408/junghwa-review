중화 반응 복습실

정리는 눌러서 펼치고, 직접 섞어 보고, 공략 4단계로 문제를 풀어 보세요.

1한 장 정리

산과 염기

산

수용액에서 H+ 을 내놓는 물질

HCl → H+ + Cl−

신맛, 금속과 반응해 수소 기체, 탄산 칼슘과 반응해 이산화 탄소

염기

수용액에서 OH− 을 내놓는 물질

NaOH → Na+ + OH−

미끌미끌함, 단백질을 녹임

수용액 속 양이온 수 = 음이온 수, 같은 수용액이면 이온 수는 부피에 비례

중화 반응

H+ + OH− → H₂O (1 : 1, 열 발생 = 중화열)

중화 반응이 일어나도 중성이라는 보장은 없다. H⁺이 남으면 산성, OH⁻이 남으면 염기성

BTB 용액: 산성 노란색 · 중성 초록색 · 염기성 파란색

구경꾼 이온

Na+ Cl− K+ 은 반응에 참여하지 않아 개수가 그대로입니다.

섞기 전 Cl⁻ 수 = 처음 H⁺ 수, Na⁺ 수 = 처음 OH⁻ 수 → 구경꾼 이온으로 반응 전 이온 수를 거꾸로 구한다

중화 반응 공략 4단계
  1. H⁺과 OH⁻만 반응한다. 나머지는 구경꾼 이온
  2. 표를 그린다. 염기 이온 먼저, 산 이온 다음 → OH⁻과 H⁺이 붙는다
  3. 혼합 용액의 액성을 파악한다. 주어진 액성은 이온 수를 알려 주는 힌트
  4. 이온의 개수를 파악한다. 산성: Cl⁻ = H⁺ + Na⁺ (+ K⁺) / 염기성: Na⁺ (+ K⁺) = OH⁻ + Cl⁻

2직접 섞어 보기

비커마다 부피를 정한 뒤 섞기를 누르면 세 비커의 용액이 오른쪽 비커로 모이고, 반응하는 이온이 물이 됩니다. 같은 진하기라면 10 mL마다 이온이 2개씩 들어 있다고 정했습니다.
